# Agency site

## Run it
Open the folder in VS Code, install the **Live Server** extension, right-click `index.html` and choose **Open with Live Server**.
(Opening index.html by double-click also works, but Live Server plays videos more reliably.)

## What to edit
- `script.js` (top of file): brand name, contact details, the 14 video slots, the 6 poster slots, services and process text.
- `style.css` (first lines): colors and fonts.
- `index.html`: page structure, rarely needs changes.

## Your files
- `videos/` reel-1.mp4 ... reel-14.mp4 (9:16)
- `posters/` reel-1.jpg ... reel-14.jpg (cover for each reel)
- `images/` poster-1.jpg ... poster-6.jpg (3:4)
Keep the same file names, or change the paths in `script.js`.
